# Project Memory — AiRCO Website (theairco.ai)

## What this project is

Next.js 16.1.6 (Turbopack) + React 19 + TypeScript + Tailwind v4 + Framer Motion + Lenis + Three.js.
Full enterprise website for **AiRCO — AI Revolution Company Pvt Ltd** (Mumbai, India).
Positioning: "Turn Data Into Intelligence" — Enterprise AI & Data Intelligence.

Rebuilt from an old "AiRCo Insights" single-page landing site into a 27-route multi-page site
using content extracted from https://www.the-airco.com/ (stored in `content/the-airco-site-content.md`).

## Deployment — IMPORTANT

- **Live site:** https://theairco.ai — Hostinger shared hosting, fronted by Cloudflare (DNS: 104.21.x.x).
- **Build:** `npm run build` → static export (`output: 'export'`) writes to `out/`.
- **`trailingSlash: true` is REQUIRED** — pages must export as `dir/index.html`.
  With `false`, Next emits `page.html` + a bare `page/` dir (RSC payloads only) → Apache
  redirects to the dir → 403. This was a real production bug; do not revert.
- **Deploy:** `python deploy-ftp.py` — mirror-syncs `out/` to remote `public_html/`,
  uploading all files and deleting stale remote ones. Credentials via env vars:
  `FTP_HOST` (default 217.21.87.58), `FTP_USER` (default u524024588.Airco), `FTP_PASS` (prompted).
  FTP port 21, passive mode. FTP account root = `/home/u524024588/domains/theairco.ai/public_html`.
  Password is intentionally NOT stored — get it from hPanel → Files → FTP Accounts.
- GitHub repo: https://github.com/dscyrus07-dev/The-Airco.ai-website (remote `origin`, branch `main`).
- Post-deploy verification: curl every route for 200; transient Cloudflare 525s can appear — retry.

- Source logos: `logo/` — `Dark_Mode_Logo__1_-removebg-preview.png` is the preferred wide white logo.
- **Navbar:** ONLY `public/logo-white.png` (wide transparent white logo) — no icon+text combo.

## Gotchas learned

- `types/globals.d.ts` declares `*.css` — fixes IDE "cannot find module './globals.css'".
- Do NOT create `public/sitemap.xml` — conflicts with `app/sitemap.ts` in export.
- Dev server: `npm run dev` → localhost:3000. Lint: `npm run lint` (3 known warnings: img
  optimization ×2, unused `state` param in components/scenes/Drone.tsx).
- Verify: `npx tsc --noEmit`, `npm run lint`, `npm run build`, then check out/.
